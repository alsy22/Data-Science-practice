## K‑Means Clustering

This folder contains the k‑means clustering analysis for identifying financial profiles among Spanish startups. The notebook covers:

- preprocessing and standardization  
- testing different values of *k*  
- selecting the final number of clusters  
- interpreting the resulting groups  

The analysis ultimately identifies five types of startups with distinct financial structures.
